## 🚀 How to Run Locally

### Method 1: Using the Built-In Node.js Server (Recommended)
Open a terminal in this directory (`c:\Users\ACER\Desktop\Namrata Ingale`) and run:

```bash
npm run dev
```
or
```bash
node server.js
```

Then visit in your web browser:
👉 **`http://localhost:3000`**

### Method 2: Direct Browser Open
Double-click `index.html` in your file explorer, or right-click `index.html` and select **Open with > Google Chrome** (or your preferred browser).

## 🌐 Deploy to GitHub Pages for Free

To publish your website at `https://NamrataIngale07.github.io/`:

```bash
git init
git add .
git commit -m "Update portfolio for Namrata Ingale with SaaS light-blue design"
git branch -M main
git remote add origin https://github.com/NamrataIngale07/NamrataIngale07.github.io.git
git push -u origin main
```

Then in GitHub:
1. Navigate to **Settings** > **Pages**.
2. Select **Branch: main** and folder **/ (root)**.
3. Click **Save**. The website will be live in minutes.
